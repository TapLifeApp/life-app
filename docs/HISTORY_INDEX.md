# Life App history and deliverables index

This folder contains the known Life App product decisions and deliverables consolidated on 2026-10-16.

- Start with `LIFE_APP_MASTER_RECORD.md` for the full product history summary and current decisions.
- Use `ROADMAP.md` for task order and status.
- Use `DEVELOPMENT_LOG.md` for work performed in the code package.
- Use `PROTOTYPE_TEST_REPORT.md` for what has and has not been verified.
- Use the draft specification and progression documents as working drafts, not approved final standards.
- Earlier prototype versions are preserved under `archive/prototype_versions/`.
- Existing Life App video assets are stored under `media/`.

Important limitation: this package consolidates available decisions and files. It cannot automatically move past ChatGPT conversations into the Project itself.
